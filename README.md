# Dissemination

This repository contains slides and other documents from communication and dissemination about ISARIC data tools.

### Slides

This is mostly slides delivered to external audiences and to ISARIC Members through the [CREDO](https://isaric.org/capacity/clinical-research-during-outbreaks-credo/) training curriculum. These files are organised by year and should be either PowerPoint (.pptx) or PDF (.pdf). The file name should be `description-yyyymmdd.pptx` or `description-yyyymmdd.pdf` so will identify the context and date.

### Reports

This is for any reports on ISARIC data tools, such as reports from ISARIC Member Assembly meetings. These files are organised by year and should be PDF (.pdf). The file name should be `description-yyyymmdd.pdf` so will identify the context and date.
